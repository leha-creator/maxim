# Корневые сертификаты для внешних систем

Сервер MAX Bot API использует сертификат Минцифры (05 §2.1). Корневой сертификат
кладётся сюда и попадает в образ бэкенда в `/etc/maxim/certs/`:

1. Скачать «Russian Trusted Root CA» в формате PEM с официального ресурса Минцифры
   (Госуслуги, раздел о сертификатах НУЦ) и сохранить как `russian_trusted_root_ca.pem`.
2. Сверить отпечаток SHA-256 с опубликованным на официальном ресурсе:
   `openssl x509 -in russian_trusted_root_ca.pem -noout -fingerprint -sha256`.
   Записать отпечаток и дату проверки в этот файл.
3. В окружении `worker` задать `MAX_CA_CERT_FILE=/etc/maxim/certs/russian_trusted_root_ca.pem`.

Без сертификата `worker` в продакшене не стартует: проверка бота (`GET /me`) не
пройдёт TLS. В разработке и тестах MAX поддельный, сертификат не нужен.
