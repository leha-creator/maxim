# Проектная документация

Биржа рекламы в каналах MAX: рекламодатель выбирает каналы в каталоге, готовит пост и платит; блогер принимает заказ, пост выходит в канале на ограниченный срок; платформа маркирует рекламу, контролирует размещение и рассчитывается с блогером.

Комплект описывает систему целиком. На его основе для каждого этапа из [роадмапа](../.ai-factory/ROADMAP.md) пишется отдельное ТЗ. Читатель — AI-агенты, которые пишут код, поэтому документы дают таблицы, идентификаторы и точные значения, а не общие описания (D-13).

## Соглашения

### Метки

Утверждение, которое опирается на решение, допущение или открытый вопрос, сопровождается меткой в скобках: `(D-03)`, `(A-10)`, `(Q-05)`. Все метки расшифрованы в [open-questions.md](open-questions.md).

| Метка | Смысл | Как относиться при написании кода |
|---|---|---|
| `D-NN` | Решение, утверждённое заказчиком | Выполнять как требование |
| `A-NN` | Допущение: рабочий вариант, заказчиком не утверждён | Выполнять как требование, но значение выносить в конфигурацию или изолировать так, чтобы смена не требовала переписывать соседний код |
| `Q-NN` | Открытый вопрос. У каждого есть рабочее допущение | Реализовать по допущению; место в коде пометить комментарием с номером вопроса |

Документ никогда не описывает два варианта сразу. Выбран один; альтернатива и цена смены записаны в реестре.

Сведения о законах и налогах взяты из вторичных источников. В тексте они помечены «проверить с юристом» и ссылкой на вопрос реестра. Опираться на них как на установленный факт нельзя.

### Структура документа

Каждый документ 01–07 начинается с блока:

- **Назначение** — на какой вопрос отвечает документ.
- **Связанные документы** — что читать вместе с ним.
- **Затронутые записи реестра** — список меток.

Разделы пронумерованы. Ссылка на раздел пишется как «03 §4».

### Идентификаторы

- Сущности, поля, значения перечислений — латиницей в `snake_case`: `placement`, `publish_at`, `awaiting_blogger`.
- В тексте при первом упоминании состояния или сущности рядом даётся русское название: `awaiting_blogger` («ожидает блогера»).
- Идентификаторы сценариев — `S-NN`, таймеров — `T-NN`, инвариантов — `I-NN`, переходов — `P-NN`.
- Новый термин сначала добавляется в [glossary.md](glossary.md), потом используется.

### Время

- Хранится в UTC, тип `timestamptz`.
- Пользователю показывается московское время (UTC+3) с подписью «МСК».
- Длительности в документах — в часах, в базе и коде — в секундах.

### Деньги

- Целое число копеек, тип `bigint`. Дробные типы для денег запрещены.
- Валюта одна — рубль; поле валюты не заводится.
- Округление при расчёте долей — вниз до копейки; остаток уходит стороне, указанной в формуле (06 §3).

### Схемы

Диаграммы — Mermaid внутри Markdown. Имена узлов совпадают с идентификаторами из глоссария.
