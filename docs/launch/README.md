# Запуск и пилот

Что нужно, чтобы бэкенд начал работать с настоящими каналами и деньгами, и кто это делает. Технические шаги — [deploy/app/README.md](../../deploy/app/README.md); здесь — общий порядок и материалы для юриста, ИП и дежурного.

Пометка **«требует действий человека»** — шаг вне репозитория: договор, подпись, подача в госорган, доступы. Значения с меткой **ПРЕДПОЛОЖЕНИЕ** придуманы и подлежат замене (список — `.ai-factory/plans/ops-readiness.md`, «Допущения»).

| Файл | О чём |
|---|---|

## Вопросы

Новые вопросы этого этапа. При слиянии их стоит внести в реестр [open-questions.md](../open-questions.md) под следующими свободными номерами; здесь номера не занимаются, чтобы не столкнуться с параллельными ветками.

| Вопрос | Что зависит | Предложение по умолчанию |
|---|---|---|
| Где проверять восстановление копии продакшена раз в квартал: 07 §8 говорит «на тестовом окружении», но данные продакшена в другие окружения не переносятся | Квартальная проверка, протокол | Временный кластер на сервере продакшена (`restore-check.sh`, `restore-pitr.sh` в томе `backup-tmp`), данные не покидают сервер; на тестовом окружении — та же проверка его собственных копий |
| Кто подписывает протокол квартальной проверки восстановления и где он хранится | Доказательство выполнения 07 §8 | ИП (П-9); протокол — в хранилище документов ИП, ссылка — в журнале дежурного |
| Нужен ли отдельный договор с хостингом и почтовым сервисом о поручении обработки ПДн (ч. 3 ст. 6 152-ФЗ) | Реестр обработки, уведомление РКН | Да, если провайдер получает доступ к данным; проверить с юристом (Q-33) |
| Срок хранения данных удалённой учётной записи, нужных для учёта (ИНН, договоры, проводки) | Обезличивание по запросу субъекта (06 §8) | 5 лет после окончания года последней операции (ПРЕДПОЛОЖЕНИЕ, по срокам хранения первичных документов) — проверить с юристом |
